# Asia Shop — ates-store.de
 
Ein vollständiges E-Commerce-Projekt als Lernprojekt, entwickelt mit **Laravel**, **React (TypeScript)** und **Inertia.js**.
 
**Live:** [ates-store.de](https://ates-store.de)
 
---
 
## Tech Stack
 
| Bereich      | Technologien                              |
|--------------|-------------------------------------------|
| Backend      | Laravel, PHP                              |
| Frontend     | React (TypeScript), Inertia.js            |
| Styling      | Tailwind CSS, shadcn/ui                   |
| Datenbank    | MySQL                                     |
| Versionierung| Git                                       |
 
---
 
## Features
 
- Produktkatalog mit Kategorien
- Warenkorb mit Validierung (Middleware)
- Benutzer- & Rollenverwaltung (Admin)
- Authentifizierung
- Mehrsprachigkeit (Laravel Language Files)
- Responsive UI mit Tailwind CSS
- Bestellverwaltung (in progress)
  
---

## Über das Projekt
Dieses Projekt entstand als persönliches Lernprojekt. Ziel ist es, eine vollständige Full-Stack-Webanwendung mit modernem Tech Stack zu entwickeln und dabei Laravel-Konzepte wie Middleware, Service Container, FormRequests und Eloquent in der Praxis anzuwenden.
